# Music box PCB
First time making PCBs in order to learn how it is done. I've decided to make a PCB for a circuit I used to built an electronic music box. 
During the project I learned how to create custom symbols and footprints, and how to, in the end, transfrom schematics into a PCB board that fits the capabilities of a manufacturer. 
Since it was my first PCB project, I went with a simple schematic, to focus on the basics.
